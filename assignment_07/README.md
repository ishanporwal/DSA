# Assignment 07 - Associative Arrays and Applications

## Markov Text Analysis Results

I used my associative array to implement Markov text analysis, which counts how frequently different words follow a given word in a text.

I tested the program on *Romeo and Juliet* by William Shakespeare, downloaded from [Project Gutenberg](https://www.gutenberg.org/ebooks/1513). The program processed **33,231 tokens** and found **4,035 unique tokens with followers**.

I also tested my implementation on a smaller sample text so I could easily verify the counts. For example, the word "the" was followed by "cat" 3 times and "dog" 2 times, which matched what I expected.

Overall, the program was able to process the full text and let me search for individual words to see which words followed them and how frequently they appeared.
